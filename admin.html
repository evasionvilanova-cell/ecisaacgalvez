Falta connectar Supabase

El panell ja no fa servir Google Sheets. Configura-ho una sola vegada (detall al README.md):

Pas 1

Crea un projecte gratuït a supabase.com

Pas 2

SQL Editor → enganxa supabase.sql (canvia el correu d'admin) → Run

Pas 3

Authentication → Users → Add user amb aquell correu

Pas 4

Copia Project URL i anon key a js/config.js al GitHub

Importar dades de l'antic Google Sheets

Copia una sola vegada corredors, patrocinadors, competicions, carreres i textos de l'antiga web (Google Sheets) a la nova base de dades. Només s'importen les taules que encara estiguin buides, així que no es duplica res.

🎨 Disseny de la web

Prova els dissenys amb Previsualitzar (només ho veus tu). Quan te n'agradi un, tria'l aquí i prem Guardar canvis: es canvia a tota la web.
